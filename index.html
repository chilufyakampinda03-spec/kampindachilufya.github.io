HTML/01

Semantic HTML

Personal website

A structured personal page with clear sections, a learning table and accessible media.

I use header, nav, main, section and footer to give the page meaning. Labels connect form controls to their descriptions, while alt text explains photographs.

CSS/02

CSS Grid & media queries

Responsive layouts

Layouts that adapt to a phone, tablet or laptop without losing readability.

CSS variables keep colours consistent. Grid arranges repeated items, and media queries change column counts on smaller screens. Padding, margins and borders demonstrate the box model.

JS/03

JavaScript & the DOM

Interactive experiences

Useful interactions that respond to clicks, searches and form submissions.

Event listeners connect user actions to functions. DOM updates change visible content, and textContent safely displays user-entered text without interpreting it as HTML.
